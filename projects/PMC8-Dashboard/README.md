# PMC8 Dashboard

This project folder is intended to host the PMC8 Dashboard community utility contributed by Wes McDonald for the OpenGOTO and Explore Scientific PMC-Eight user community.

PMC8 Dashboard provides Python-based utility tools and documentation for PMC-Eight support, configuration, and related workflows. It is being staged here as an OpenGOTO Community project so source code, documentation, release packages, and checksums can be maintained in a public Explore Scientific location.

## Project Status

Status: project scaffold created; contributor approval received from Wes McDonald to host the Dashboard source and release assets as an OpenGOTO Community project; source and release asset import pending.

## Intended Purpose

PMC8 Dashboard is intended as a community utility for PMC-Eight users and support workflows. It is separate from the official PMC-Eight firmware, ASCOM driver, INDI driver, UFCT utility, and ExploreStars Envision app.

## Review Status

Before public announcement or promotion from Explore Scientific support pages, review should confirm:

1. Contributor redistribution/source-publication approval is documented.
2. The imported files match the Dashboard version intended for public release.
3. Source code does not include private credentials, private firmware source, or unrelated proprietary files.
4. Third-party notices and license terms are included.
5. Windows and macOS release ZIPs include their own notices and user documentation.
6. SHA-256 checksums are generated for release assets.
7. Basic installation and operating instructions are available.
