# PMC-Eight ALPACA Server v1.2.2 Staging

This folder is the local administrator staging area for the upstream `v1.2.2` release artifacts downloaded from:

https://github.com/nigeldun/ES_PMC8_ALPACA/releases/tag/v1.2.2

The zip files in this folder are intentionally ignored by git. They are uploaded to the Explore Scientific GitHub Release instead:

https://github.com/ExploreScientific/OpenGOTO-Community-Projects/releases/tag/pmc-eight-alpaca-server-v1.2.2

Expected local artifacts:

| Platform | Artifact |
| --- | --- |
| Windows x64 | `publish-win-x64.zip` |
| Linux x64 | `publish-linux-x64.zip` |
| Linux ARM64 | `publish-linux-arm64.zip` |
| macOS x64 | `publish-macos-x64.zip` |
| macOS ARM64 | `publish-macos-arm64.zip` |

See `../../checksums/SHA256SUMS.md` for SHA-256 verification hashes.
