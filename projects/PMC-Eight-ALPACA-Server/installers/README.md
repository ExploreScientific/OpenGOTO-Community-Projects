# Installers

Contributor permission has been received from Prosaic Alto for Explore Scientific to host and redistribute the submitted PMC-Eight ALPACA Server package files.

The current mirrored upstream release is `v1.2.2` from:

https://github.com/nigeldun/ES_PMC8_ALPACA/releases/tag/v1.2.2

The recommended public download location is the Explore Scientific GitHub Release:

https://github.com/ExploreScientific/OpenGOTO-Community-Projects/releases/tag/pmc-eight-alpaca-server-v1.2.2

Large release artifacts should continue to be attached to GitHub Releases instead of committed directly to the repository unless they are intentionally tracked through Git LFS.
