# PMC-Eight ESP32 Serial Flash v1.3 / Firmware ES4.2.3

Explore Scientific mirror of Wes McDonald's release. Mirrored 2026-10-22; the ZIP and upstream checksum file are unchanged.

Use this rescue package only when OTA is unavailable because the ESP32 firmware is missing, corrupted, or too old. It installs recovery firmware ES4.2.3 by design and includes PMC-Eight Propeller firmware 20A02.2.0.1. Read the guide before opening the enclosure or fitting a jumper. After recovery, run OTA v2.5 to install ES4.2.32.
