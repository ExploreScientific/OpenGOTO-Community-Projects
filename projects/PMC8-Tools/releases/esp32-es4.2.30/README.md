## Verified Firmware

The upstream release identifies the ESP32 firmware as `ES4.2.30`.

The related Wes landing-page update also references mount firmware `20A02.2.0.1`; the OpenGOTO source snapshot refresh includes the `pmc8-firmware` branch README, while firmware payload binaries remain release/package assets rather than git-tracked source files.
