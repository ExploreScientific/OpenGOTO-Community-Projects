# PMC8 Home Network Config

PMC8 Home Network Config is a Windows utility by Wes McDonald for configuring Explore Scientific PMC-Eight WiFi modules to join a home network over USB serial.

The utility supports ESP32, ESP8266, and RN-131 WiFi module families. It lets a user select the module type and COM port, enter the home-network SSID and password, write those credentials to the module, and read back the LAN IP address assigned by the router.
