# Spiral Search Bridge

Spiral Search Bridge is a cross-platform utility by Wes McDonald for running an expanding spiral search pattern through an ASCOM Alpaca-compatible telescope mount.

It runs as a local web server and can be controlled from a browser on a laptop, tablet, or phone. The v2.0 release includes Windows, macOS, and Linux ARM64 builds.

## Project Status

Status: Documentation, notices, and v2.0 release assets mirrored for Explore Scientific users.

The public branch and release contain pre-built binaries and documentation. The application source is maintained separately by the contributor.
