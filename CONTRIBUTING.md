# Contributing OpenGOTO Community Projects

Thank you for contributing to the OpenGOTO and PMC-Eight ecosystem.

To submit a project for Explore Scientific review, provide the following:

- Project name.
- Contributor name or preferred public credit.
- Short description of what the project does.
- Supported operating systems.
- Hardware requirements.
- Installation instructions.
- User instructions.
- Source code, if it is intended to be public.
- Built executables or installers, if applicable.
- License or written redistribution permission.
- Version number or release date.
- SHA-256 checksums for binaries and installers.
- Known issues or limitations.

Do not include private credentials, private firmware source, private repository links, customer data, unpublished internal documents, or files that you do not have permission to redistribute.
